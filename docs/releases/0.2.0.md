# Longreach Qt 0.2.0

Source-only pre-release candidate. The release has not been tagged or
published; the release date will be set at publication.

Longreach Qt 0.2.0 updates Qt 6 to 6.8.5 and carries security fixes across
Qt 4.8.7, Qt 5.15.19 and Qt 6.8.5, retaining the existing platform floors.

## Distribution

This pre-release contains the source tree, patches, build tooling, test
suite, licences and recorded results. Build the SDKs locally using
[getting started](../getting-started.md). Prebuilt Windows and Linux SDK
images are deferred to a later release. macOS SDK images are excluded
under the project's [release policy](../releasing.md).

## Changes since 0.1.0

- Qt 6 moves from 6.8.4 to 6.8.5, including the adapted Windows 7 and macOS
  compatibility patches and the macOS cross-build fix.
- Qt 4, Qt 5 and Qt 6 carry the security backports listed in
  [CHANGELOG.md](../../CHANGELOG.md) and [backports](../backports.md).
- Saving a QDom attribute, doctype or document fragment on its own keeps
  the earlier output after the XML security fixes.
- Native print-dialog checks run in a child process with a timeout;
  preview checks account for a missing default printer.
- The VMware runner supports encrypted guests, including Windows 11 VMs.
- Updated runtime records distinguish passed, failed and skipped checks
  and identify the tested executables by SHA256.

The [final Windows and macOS matrix](../results/windows-macos-final-20261030.md)

run: **176 application runs, 9934 passed checks, 0 failed, 2144 skipped**.

|--------|-------------------------|
| Windows XP SP3 | Qt 4 i386; Qt 5 i386 |
| Windows 7 SP1 x64 | Qt 4 i386/amd64; Qt 5 i386/amd64; Qt 6 amd64 |
| Windows 11 x64 | Qt 4 i386/amd64; Qt 5 i386/amd64; Qt 6 amd64 |
| Mac OS X 10.6.3 and OS X 10.7.5 | Qt 4 i386; Qt 5 i386/amd64 |
| macOS 10.13.6 | Qt 4 i386; Qt 5 i386/amd64; Qt 6 amd64 |

The current Linux amd64 suites also pass on both Debian 13 and CentOS 7:
Qt 5 has 511 passed / 0 failed / 87 skipped checks per system; Qt 6 has
528 / 0 / 51. All eight applications pass in each run. The
[build and Linux test report](../results/qt5-qt6-build-and-tests-20261030.md)
records the 15 Qt 5/6 target builds and Qt 6 host tools, all successful.

The source commits recorded when the suites were built are `db747c3`
for Qt 4 and `ea9b0aa` for Qt 5/6. The history cleanup below preserves
their source trees. The release-preparation commits change documentation;
they do not change the tested implementation or build inputs.

## Known limitations and remaining validation

- The Qt 4 NT4 `quick-qml-gallery` failure remains under investigation.
  This candidate makes no claim of a new successful NT4 run.
- Windows ARM64 and Apple silicon have build evidence but no runtime run
  in the candidate's new VM matrix.
- Qt 4 PowerPC was not rerun: the available Snow Leopard VM has no Rosetta.
  Earlier PowerPC and oldest-system records retain their original dates
  in [platforms](../platforms.md).
- Other older platform records are historical evidence; the new matrix
  above is the scope of the fresh Windows/macOS validation.
- A full rebuild starting with an empty downloads directory has not been
  repeated during this release preparation. The available downloads pass
  their pinned SHA256 checks; cached build results are recorded separately.
- Skips remain visible in each result and are excluded from pass counts.

The existing [licensing guide](../licensing.md) and per-file licence texts
apply. The default build profile remains `gpl-enabled`.
