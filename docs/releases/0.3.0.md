# Longreach Qt 0.3.0

Source-only pre-release candidate. The tested implementation is
`62932c4e59afdc7e0e328d96012f6d8dcaf9812f` on `main`. Release preparation
adds documentation and packages the source tree locally.

## Changes since 0.2.2

The default SDK builds for 17 targets use upstream Clang and static libc++
from LLVM 21.1.8. The kit builds Qt 4.8.7, Qt 5.15.19 and
Qt 6.8.5. The `v0.2.2` tag preserves the previous GCC and MinGW recipes.
The LLVM builds still use the target headers and CRT required by each
platform. GCC bootstraps LLVM, and Qt 4 for Jaguar retains its legacy
driver, libgcc and OpenSSL compiler for the PowerPC ABI.

- The migrated SDKs use their canonical Dockerfiles. Qt 4 Sarge, Qt 5
  Lucid and Qt 5 Windows XP share one recipe for their two architectures.
- Make prepares the required toolchain images. The `build-*` entry points
  reuse current SDKs by input fingerprint. Qt 4 and Qt 5 examples build
  in a separate image stage using the installed SDK.
- Qt 6 cross-builds prepare native host tools and target dependencies.
  `QT6_SOURCE` accepts an explicit source archive. The sequential
  coordinator retains its offline build and resume workflow.
- Qt 5 Trusty applies the QtScript call-frame fix. The macOS amd64 build
  carries the selected deployment target through Qt and the examples.

## Validation

The migration produced **17 successfully built and runtime-tested SDKs**.
The **20 successful platform runs** each passed all eight ordinary
applications and **25/25 strict C++23 checks with zero skips**. Optional
checks in the ordinary applications are counted separately in the
[validation reports](0.3.0-migration.md#validation-complete).

| Qt | SDK targets | Systems in the migration runs |
|---|---:|---|
| 4.8.7 | 6 | Debian 3.1 Sarge i386 and amd64, Simplified Chinese Windows 95 OSR2 i386, Windows XP x64 SP2, Mac OS X 10.4.10 Tiger i386 and Mac OS X 10.2 Jaguar PowerPC |
| 5.15.19 | 7 | Ubuntu 10.04 Lucid i386 and amd64, Ubuntu 14.04.6 Trusty ARM64 userland, Windows XP SP3 i386 and XP x64 SP2, Mac OS X 10.6.3 Snow Leopard i386 and amd64 |
| 6.8.5 | 4 | Debian 13 and CentOS 7 on amd64, Debian 12 and CentOS 7 ARM64 userlands, Windows 7 SP1 and Windows 11 on amd64, macOS High Sierra 10.13.6 amd64 |

Follow-up builds checked the missing-toolchain path on Qt 4 XP x64, a
10.7 deployment override on Qt 5 macOS amd64, and a source archive with
a different SHA-256 on Qt 6 Windows amd64. Repeating each build preserved
its SDK image ID. The [migration notes](0.3.0-migration.md#build-path-rechecks)
record the exact scope and the Ubuntu mirror fallback.

GitHub Actions `Repository checks` passed on the implementation commit.
The job covered Python syntax, tooling regressions, API coverage, the
licence matrix and the repository scan. The SDK and guest results above
come from the recorded local runs. [GitHub Actions run](https://github.com/OpenKaryon/longreach-qt/actions/runs/43899573692)

## Scope and limits

- Windows ARM64 and macOS ARM64 for Qt 5 and Qt 6 are deferred from the
  default LLVM migration. Previous build and binary-audit evidence is
  available. Matching runtime validation is pending.
- Windows 95 runtime coverage uses Simplified Chinese OSR2 with Winsock 2.
  The Russian OSR2 code pages cannot represent the mixed-script filename
  in the strict filesystem check. [Windows 95 target notes](../targets/qt4-windows.md)
- The Linux ARM64 runs use QEMU user mode and a Docker host kernel.
  Hardware graphics on the oldest guests, including Metal on High Sierra,
  falls outside the recorded coverage. [Platform notes](../platforms.md)
- A full rebuild of every target from an empty downloads directory has
  not been repeated for this candidate.

## Distribution

The candidate contains the source tree, build recipes, patches, examples,
licences and reports. Build SDKs locally using [getting started](../getting-started.md).
Prebuilt SDK images are deferred. The source archive and its checksum are
prepared locally for review, with tagging and publication handled as
separate release steps. [Release process](../releasing.md)
