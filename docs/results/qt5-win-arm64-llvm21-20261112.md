# Qt 5.15.19 with LLVM 21.1.8 on Windows arm64

The clean repository recipe built the static Qt SDK and all nine example
executables in 40 minutes 7 seconds. It reused the upstream Clang, LLD,
compiler-rt, libunwind and libc++ toolchain with the source-built
MinGW-w64 13.0.0 UCRT sysroot.

All 234 installed static archive paths matched the existing Windows ARM64
SDK. The configuration retained Schannel and desktop OpenGL. The
existing profile excludes Mapbox GL, the Qt Quick D3D12 backend and
Qt WebEngine.
All 157 qmake module files and 314 qmake feature entries matched the existing SDK.

All nine executables compiled in strict C++23 mode. The PE audit
confirmed ARM64 and subsystem version 10.0. The
[JSON record](qt5-win-arm64-llvm21-20261112.json) contains executable hashes
and DLL imports.

Windows 10 on ARM runtime verification is deferred. The local test host
and configured Windows guests are x64. The 25 C++23 checks and ordinary
GUI examples need an ARM64 Windows run to record runtime outcomes.

```sh
make qt5-win-arm64-llvm-examples PARALLEL_JOBS=3
```
